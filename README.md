# Java-Projects
//This program uses a List and an Array List to make a To-do list with tasks and examples. The program getter and setter methods, a for loop, Override annotation, for loop, and includes use of library to create ToDoList_Project program

Technologies used: Java 8
Classes, Objects, Methods, Array List, and For loop are mainly used within the program

Prerequisities:
Java 8 installed
Eclipse/or any IDE installed to run program

How to run
1.  Clone or download this repository to your local computer
2. Open the project in your preferred IDE
3. Run the ToDoListApp.java
4. The program will print the tasks within ToDoList and the current setting to the console

Example of piece of program

//Create a new To-Do List
ToDoList todoList = new ToDoList();

//Add tasks 
todoList.addTask("Review Data Structures");
todoList.addTask"Make Java Projects");

//Marking tasks as done/complete

todoList.markTaskCompleted(0);

//method prints all tasks stored within Array List into program

todoList.printTasks();



Expected output:

Current To-Do List:
1. [✓] Review Data Structures
2. []  Make Java Projects
